> 服务市场上架的硬门槛 + 长期经营的护城河。

| 项           | 要求                                       | 状态 |

## 3. 数据安全

### 3.1 敏感数据分级

| 级别       | 数据                            | 保护措施                   |
| ---------- | ------------------------------- | -------------------------- |
| L4（核心） | 手机号、身份证、收货地址、Token | KMS 加密、字段级权限、审计 |
| L3（敏感） | 订单金额、买家昵称、店铺数据    | 库级加密、HTTPS            |
| L2（一般） | 商品数据、类目                  | HTTPS                      |
| L1（公开） | 营销内容                        | —                          |

### 3.2 加密方案

- 传输：应用生产配置强制 HTTPS origin；生产入口仍须由网关/负载均衡启用 TLS 1.2+、HSTS 和证书自动续期
- 存储：当前手机号、地址、OAuth Token 与 BYOK 使用 AES-256-GCM；信封加密仍待目标 KMS 接入
- 密钥管理：当前由运行环境注入；上线前必须迁移至 Secret Manager/KMS 并完成轮换演练

### 3.3 访问控制

- 当前 Supabase JWT 映射内部用户并按 `user_id` 隔离业务数据；更细粒度 RBAC/后台角色仍待实现
- 生产数据库访问和高风险恢复操作必须二次审批
- 写操作、失败鉴权和 OAuth 已进入审计表，默认留存 180 天；外部审计归档策略仍待目标环境确认

## 4. 内容合规

### 4.1 文本敏感词库（DFA 匹配）

| 类别     | 来源                     | 规模     |
| -------- | ------------------------ | -------- |
| 极限词   | 国家市场监督管理总局公布 | 200+     |
| 医疗用语 | 自建 + 公开              | 500+     |
| 政治敏感 | 公开词库                 | 1000+    |
| 平台违禁 | 各平台规则爬取           | 平台特定 |
| 类目专项 | 食品/化妆品/保健等       | 类目特定 |

### 4.2 图像合规

- 二维码 / 联系方式检测（拒绝引流）
- 水印 / 商标检测
- 商品与类目一致性 VLM
- AI 生成内容标识（明水印 + EXIF 元数据）

### 4.3 生成式 AI 合规

依据《生成式人工智能服务管理暂行办法》：

- 服务提供者备案
- 内容标识（明显或元数据）
- 训练数据合法
- 用户输入审核
- 用户可投诉、可申诉

## 5. 业务风控

| 风险       | 检测               | 处置            |
| ---------- | ------------------ | --------------- |
| 恶意刷单   | 单 IP/设备多账号   | 限流 + 人工审核 |
| 滥用 AI    | 单用户日调用量异常 | 限流 + 升级提示 |
| 异常铺货   | 短时间大量违规商品 | 暂停 + 通知     |
| Token 异常 | 异地调用           | 二次验证        |
| 欠费       | 信用额度超限       | 暂停 AI 服务    |

## 6. 反洗稿与原创化

抖音等平台反铺货严，需要"原创化"：

- 标题改写（同义替换 + 句式重构）
- 主图重绘（背景换、元素重组、风格迁移）
- 详情页重排版（拆段、加自有模板）
- 主图 EXIF / 哈希必须不同

## 7. 应急预案

| 场景              | 预案                              |
| ----------------- | --------------------------------- |
| 平台 API 整体故障 | 多平台兜底、状态页通知用户        |
| 大规模封号        | 告警 + 紧急下架功能开关           |
| LLM 不可用        | 多模型降级 + 模板兜底             |
| 数据泄露          | 30 分钟内通报 + 72 小时内监管报备 |
| 算法被滥用        | 模型限流 + 人工审核兜底           |

## 8. 用户协议关键条款（要点）

- 用户授权范围明确
- AI 生成内容版权归属（建议归用户但平台保留使用权）
- 数据使用边界（不做训练、不二次售卖）
- 服务可用性 SLA 与赔偿
- 争议解决与管辖

## 9. 隐私政策必备

- 收集信息清单
- 第三方 SDK 清单（含 LLM 供应商）
- 数据存储地与期限
- 用户权利（查询、删除、注销）
- 未成年人保护
- 联系方式
