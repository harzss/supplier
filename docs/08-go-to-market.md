# 商业化与冷启动方案

| 套餐 | 月费 | 年费（折后） | 目标人群 | 关键限制 |

## 2. 渠道策略

### 2.1 1688 服务市场（主战场）

- **冷启动**：免费 7 天 + 真人客服 + 案例输出
- **目标**：3 个月内评分 4.85+，销量 5 万套
- **运营**：每周新功能更新公告 + 用户故事
- **推荐位**：销量 + 评分双高 → 自然推荐

### 2.2 抖音小店服务市场

- 抖店服务市场上架
- 抖音卖家社群、商家学习中心投放

### 2.3 内容营销

| 渠道 | 内容形式 |
|---|---|
| 小红书 | "新手开店第一周"系列、选品案例 |
| 抖音 | 知识 IP（抖店运营技巧）+ 软植入 |
| 公众号 | 行业研报、深度教程 |
| B 站 | 工具评测、SaaS 拆解 |
| 知乎 | 问答精耕（"如何选品"等长尾词） |

### 2.4 社群运营

- 商家私域群（按地域 / 类目分群）
- 周打卡 + 案例分享
- 月度爆款榜单

### 2.5 渠道分销

- 招募淘宝/抖音电商培训机构作为分销商
- 给 30% 首年返点
- 提供联合品牌物料

## 3. 冷启动六周计划

| 周 | 目标 | 关键动作 |
|---|---|---|
| W1 | 上架就绪 | 完成等保备案、提交服务市场审核 |
| W2 | 内测启动 | 邀请 30 家种子商家免费试用 |
| W3 | 反馈迭代 | 每天发 1 个修复 + 1 篇案例 |
| W4 | 公测 | 服务市场上线，启动小红书内容 |
| W5 | 增长引擎 | 开启邀请奖励 + 抖音内容投放 |
| W6 | 评估转化 | 复盘北极星指标，决定加大投入或微调 |

## 5. 单位经济（UE）测算

> 假设：基础版 ¥39/月，年付率 60%，平均单店月 GMV ¥3万

| 项 | 值 |
|---|---|
| ARPU（月） | ¥48（混合套餐） |
| 单店月 AI 成本 | ¥9（≤ 20%） |
| 服务器分摊 | ¥3 |
| 客服分摊 | ¥4 |
| 平台分成（服务市场 30%） | ¥14.4 |
| **毛利** | **¥17.6（37%）** |
| CAC（混合渠道） | ¥80 |
| 回本周期 | ~5 个月 |
| LTV（24 月留存） | ¥420 |
| **LTV/CAC** | **5.25** |

> 关键杠杆：将 AI 成本压到 ¥6 + 提高年付率 → LTV/CAC > 7。
