## 4. 证据管理规则

1. 仓库只保存脱敏索引、摘要、哈希和可公开截图；原始资质、账号凭证和个人信息保存到经负责人批准的受控存储。
2. 每个外部证据至少记录：证据 ID、所有者、生成时间、适用环境、候选 Git SHA、校验哈希、访问权限和过期/复核时间。
3. 截图与视频必须遮盖邮箱、手机号、地址、Token、Cookie、Secret、付款信息和平台敏感标识；不能用 Mock 或演示数据冒充真实平台回读。
4. 测试账号密码采用一次性仓库外通道传递，提交后立即轮换，审核结束后撤销会话、平台授权和账号。
5. 法务或平台规则发生变化时，新版本必须重新审批；不能仅修改 Markdown 的版本号。
