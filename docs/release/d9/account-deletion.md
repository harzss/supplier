# Supplier 账号注销与数据删除流程（内部执行底稿）

> **当前未证明有可用的端到端账号注销功能。** 本文件定义发布前必须实现和演练的流程，不得作为“用户现在已经可以完成注销”的对外说明。

## 1. 概念边界

- **平台解绑**：撤销抖店/1688 OAuth 并停止后续平台调用，不等于删除 Supplier 账号或历史业务记录。
- **账号停用**：拒绝新登录/真实任务并保留待处理数据，不等于永久删除。
- **账号注销**：验证用户请求后终止 Supplier 账号，并按批准规则删除或匿名化相关数据。
- **法定/争议留存**：依法或为解决交易、退款、安全和审计争议保留的最小记录；必须有依据、期限和访问控制，不能成为无限期保留的借口。

## 2. 用户申请入口（发布前拟定）

1. 用户从登录后的设置页或已验证客服渠道发起注销申请。
2. 页面展示影响范围、尚未完成的订单/采购/退款、可能保留的数据类别和预计完成时间。
3. 用户完成身份核验并二次确认。
4. 系统生成不含邮箱、手机号、地址和凭证的请求编号，供用户查询进度。

当前设置页入口、隐私/客服渠道、身份核验规则和完成时限均为 **P0 TODO**。在入口上线前不得在隐私政策或 FAQ 中写成现有能力。

## 3. 执行状态机

| 状态               | 进入条件                                        | 允许动作                           | 禁止动作                   |
| ------------------ | ----------------------------------------------- | ---------------------------------- | -------------------------- |
| `requested`        | 已收到申请并生成请求 ID                         | 身份核验、风险检查                 | 删除数据、发送平台副作用   |
| `verified`         | 身份和账号控制权已核验                          | 冻结真实任务、建立数据清单         | 新发布、新采购、新发货     |
| `blocked_business` | 存在未完成订单/采购/退款/争议或依法必须处理事项 | 告知原因、最小化继续处理、定期复核 | 把阻塞无限期静默挂起       |
| `revoking_access`  | 无业务阻塞或已批准受控继续                      | 撤销会话、平台授权、worker 和密钥  | 继续使用已撤销 Token       |
| `deleting`         | 删除计划和留存例外已审批                        | 删除/匿名化、备份到期标记、验证    | 仅删除 Auth 而遗漏业务数据 |
| `completed`        | 所有步骤和验证通过                              | 向用户发送完成通知                 | 恢复账号或重用旧 subject   |
| `failed_review`    | 任一步结果未知或验证失败                        | 保持停用、升级人工、安全修复       | 猜测删除成功或盲目重试     |

状态名是流程设计，不表示当前数据库已实现该模型。

## 4. 发布前必须实现的执行步骤

1. **核验申请**：使用已登录会话和二次验证；客服人工处理时仅收集最低必要信息，不索要密码、验证码、Token、Cookie 或完整收货信息。
2. **冻结副作用**：停用用户、撤销活跃会话，禁止发布、订单同步、采购、物流和后台 worker 获得新所有权；等待已开始任务排空或进入人工处置。
3. **检查业务阻塞**：列出未完成订单、1688 采购、人工付款、物流、退款/售后、服务市场退款和安全事件；向用户说明可执行与必须保留部分。
4. **撤销外部授权**：按平台能力撤销抖店和 1688 OAuth，清除本地 Token 密文并回读停用状态；记录脱敏结果，不记录 Token。
5. **删除或匿名化**：按批准的数据映射处理账号、店铺、收藏、草稿、任务、平台映射、订单、采购、物流、售后、异常、AI 用量、BYOK 密钥、订购投影和素材。
6. **处理不可直接级联的数据**：当前模型包含可置空审计用户关联及限制删除的服务市场关系；工程必须显式验证删除顺序、匿名化规则和 referential integrity，不能假设 `User` 级联解决全部数据。
7. **删除 Supabase Auth 身份**：仅在业务数据处理达到可验证状态后删除 Auth 用户，防止先失去控制权映射而留下孤儿数据。
8. **备份与日志**：为依法保留的最小记录设置到期时间和严格权限；在备份自然到期/受控清除前不得承诺即时物理擦除。
9. **验证**：旧密码、refresh token 和现有会话不可用；业务 API 无法读取旧租户；旧 OAuth/BYOK 密钥不可调用；公开素材按规则删除；其他租户数据不受影响。
10. **通知与申诉**：用已验证渠道发送结果、保留类别/依据/期限和申诉方式；通知中不包含敏感业务数据。

| ---------------------------- | -------------------------------------------- | ---------------------------------- | -------------------------------------------------- |
| Supabase Auth、会话          | 撤销会话后删除身份                           | 顺序错误造成孤儿数据或无法验证请求 | 法务 + 工程；`P0-EVIDENCE-D9-DELETE-AUTH`          |
| 用户档案、收藏、草稿、配置   | 删除                                         | 外键和异步任务残留                 | 工程；`P0-EVIDENCE-D9-DELETE-PROFILE`              |
| 抖店/1688 店铺和 Token       | 撤销授权、清除 Token；历史标识按批准规则处理 | 平台撤销失败、迟到 worker          | 平台集成；`P0-EVIDENCE-D9-DELETE-OAUTH`            |
| 订单、采购、物流、售后和金额 | 删除、匿名化或依法限期保留                   | 交易/退款/财税/争议义务尚未确认    | 法务 + 财务；`P0-EVIDENCE-D9-DELETE-TRANSACTION`   |

| 服务市场订购与退款记录       | 按账务/平台义务限期保留或匿名化              | `Restrict` 关系、对账和退款争议    | 法务 + 商业化；`P0-EVIDENCE-D9-DELETE-MARKETPLACE` |
| AI 用量和 BYOK 密钥          | 立即销毁密钥；用量按批准规则删除/匿名化      | 密钥副本、供应商留存               | 安全 + AI；`P0-EVIDENCE-D9-DELETE-AI`              |
| Storage 素材                 | 删除用户专属对象和公开 URL                   | CDN 缓存、平台已复制素材           | 工程 + 产品；`P0-EVIDENCE-D9-DELETE-ASSET`         |
| 审计/安全日志                | user 关联置空或依法限期保留                  | 180 天当前仅为配置默认值           | 法务 + 安全；`P0-EVIDENCE-D9-DELETE-AUDIT`         |
| 备份                         | 标记删除请求并在批准期限到期时清除/不可恢复  | PITR/快照粒度和恢复后再删除        | 运维 + 法务；`P0-EVIDENCE-D9-DELETE-BACKUP`        |
| 客服与权利请求               | 限期保留最小请求证明                         | 身份核验材料过度收集               | 客服 + 隐私负责人；`P0-EVIDENCE-D9-DELETE-SUPPORT` |

## 6. 验收用例

- 专用测试账号存在收藏、草稿、平台授权、订单/采购关联、AI 用量和素材时可得到完整数据清单。
- 存在未完成人工付款或退款时进入 `blocked_business`，不会继续外部副作用。
- 无阻塞账号完成注销后，登录、refresh、旧会话、业务读取、OAuth 和 BYOK 调用均失败。
- 审计保留项不含原始 IP、Token、Cookie、密钥或完整收件信息，且留存到期可执行。
- 注销一个租户不修改另一个测试租户的任何记录。
- 平台撤销、数据库写入、Storage 删除或 Auth 删除结果未知时停在失败复核，不重试不可逆步骤。
- 从备份恢复注销前快照后，删除请求可重新应用，旧账号不会重新获得访问权。

## 7. 仓库外证据要求

每次演练记录候选 SHA、环境、匿名请求 ID、各步骤开始/结束时间、影响行数摘要、平台撤销回读、Auth/session 验证、跨租户负向验证、备份处置和审批人。不得记录测试账号密码、邮箱全文、Token、完整个人信息或数据库连接串。
