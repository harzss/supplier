# D9 数据处理清单（内部核对稿）

> 状态：依据当前仓库模型和邀请制范围建立的盘点骨架，不是已获法务批准的数据地图。生产资源、第三方合同、部署区域、处理依据、留存期和跨境路径必须另行核验。

## 1. 使用说明

- 适用范围：Supplier 抖店 + 1688 邀请制审核测试版。
- 环境事实必须以待提审候选的生产配置为准；staging 结果不能替代生产核验。
- “保护措施”列描述当前代码意图或门禁，不代表生产已完成密钥轮换、访问审计或灾备验收。
- 清单和证据不得包含密码、Token、Cookie、Secret、完整手机号/地址或原始资质文件。
- 法务须逐项确认处理依据、敏感个人信息必要性、单独同意、数据主体权利及留存例外。

## 5. 跨境与公开访问检查

- 任何服务的公司注册地或控制面在境外，不等同于已证明发生或未发生数据出境；必须按真实数据路径、部署区域、远程访问和子处理者逐项评估。
- AI 模型请求、Railway/Supabase/Cloudflare 控制面、日志和客服工具是重点核查对象。
- 当前图片素材候选使用可公开读取的 Storage bucket；发布前必须确认其中只含可公开的商品素材，不得包含收件信息、密钥、内部证据或未经授权的图片。
