# Supplier 客服、事件响应与服务目标（内部底稿）

> **当前没有已批准的正式客服入口或合同 SLA。** 本文件用于定义邀请制测试版的值守和审核材料结构；所有渠道、人员、时段、响应时间、补偿和法律通知义务必须在发布前确认。

## 1. 适用范围

- 仅适用于 Supplier 抖店 + 1688 邀请制审核测试版和专用审核账号。
- 邀请制阶段采用低流量、人工付款、人工售后和人工异常处置。
- 抖店、1688、Supabase、Cloudflare、Railway、模型服务、网络和用户自身店铺配置属于依赖边界，但不能用“第三方故障”代替必要的通知、保护和恢复。
- 本文件中的内部处理流程不是赔偿承诺；正式 SLA 必须单独经过法务批准并与可观测性数据一致。

## 3. 问题分级

| 等级    | 判定示例                                                                                    | 立即保护动作                                               | 处理所有者                   |
| ------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------- |
| P0 严重 | 跨租户数据、疑似数据泄露、重复采购/重复发货、错误收件人、资金风险、全体不可用且无法安全降级 | 停止相关真实写入和 worker；保护证据；启动安全/业务事件流程 | 值班工程 + 安全 + 运营负责人 |
| P1 高   | 单个真实订单/采购/物流卡死，平台状态未知，OAuth 大面积失效，审核关键路径不可用              | 阻断重复动作；进入人工处置；核对平台回读                   | 值班工程 + 运营              |

| P3 低   | 使用咨询、文案/样式、小范围建议                                                             | 进入常规队列                                               | 客服 + 产品                  |

分级必须按实际影响升级，不能因邀请制或用户数量少而降低跨租户、资金、错单和漏单事件等级。

## 4. 处理流程

1. **受理**：生成工单 ID，确认影响对象、首次发生时间和脱敏 request ID；不索取秘密信息。
2. **保护**：对可能产生外部副作用的事件先关闭对应开关/账号任务，避免重复发布、采购或发货。
3. **核对**：以抖店/1688 权威回读、数据库状态、审计和平台关联 ID 为依据，不用用户截图或本地成功猜测远端状态。
4. **沟通**：按已批准频率更新“已知影响、已采取保护、下一次更新时间”，结果未知时明确说未知。
5. **恢复**：先在受控范围验证，再逐步恢复；失去 worker 所有权、Token 失效或快照不一致时继续阻断。
6. **关闭**：用户/运营可核对最终状态；P0/P1 完成复盘、纠正措施、负责人和复发验证。

## 6. 维护、故障与安全事件通知

- 计划维护：说明影响、开始/预计结束、是否停写和回滚条件；邀请制真实订单窗口必须取得运营批准。
- 非计划故障：先保护订单、资金和数据，再恢复；不得在不确定时重复外部动作。
- 数据/安全事件：由安全和法务判断通知用户、平台和监管机关的对象、内容和时限；本底稿不虚构固定法定时限。
- 恢复完成：给出可核验的恢复时间、受影响范围、数据/订单最终状态和仍需用户处理的事项。

## 7. 不属于当前承诺的能力

- 7×24 正式客服、固定可用率、故障赔付或灾难恢复时间；
- 平台 API、平台审核、供应商发货或第三方网络的保证；
- 批量经营、自动采购、免密付款、自动退款、自动售后和未验收包裹；
- AI 输出准确性或 AI 服务持续可用；
- 公开商用或 10～30 家规模的服务能力。

以上边界不能免除 Supplier 对自身安全控制、幂等、状态核对、用户通知和合理恢复的责任。

## 8. 审核与演练证据

- 客服渠道真实可达，审核员/邀请用户能收到工单号和人工回复。
- P0 场景可以在不暴露秘密信息的情况下升级到工程、安全、运营和主体负责人。
- 告警、状态页/公告、停写、回读、恢复和复盘各有时间戳证据。
- 工单系统按租户/权限隔离，并有留存、导出和删除规则。
- 值班交接包含未完成订单、采购、退款和平台状态未知项。
